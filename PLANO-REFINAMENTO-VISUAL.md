# Plano de Refinamento Visual — Dr Clean

## Objetivo

Transformar o site da Dr Clean em uma experiência **mais sofisticada, bonita, confiável e atraente**, mantendo o foco principal em conversão de clientes pelo WhatsApp.

O refinamento deve funcionar muito bem em **celular, tablet e desktop**, sem perder as funcionalidades já existentes.

## Regras do projeto

- Trabalhar somente na branch `manutencao`.
- Manter HTML, CSS e JavaScript separados.
- Não adicionar React, Vue, Angular, TypeScript ou outro framework de aplicação.
- Não remover funcionalidades existentes sem necessidade.
- Priorizar desempenho, acessibilidade, responsividade e conversão.
- Evitar excesso de efeitos, animações ou elementos que deixem o site pesado.
- Corrigir problemas encontrados durante cada etapa antes de avançar.
- Depois de cada bloco, fazer revisão completa antes de seguir para o próximo.

# Regra para execução dos blocos

Cada bloco deverá ser executado **um por vez**.

Ao terminar um bloco:

1. Revisar o que foi implementado.
2. Verificar se está funcional.
3. Verificar se ficou visualmente coerente.
4. Corrigir problemas encontrados.
5. Confirmar o bloco como concluído.
6. Somente então avançar para o próximo bloco.

## Comando de revisão padrão

> **Revise todo o bloco implementado. Verifique se está correto, funcional, responsivo e coerente com o projeto. Identifique erros, falhas, código desnecessário ou pontos que possam ser melhorados. Corrija e refine o que for necessário, sem alterar funcionalidades já definidas ou fugir do escopo do projeto. Ao finalizar, confirme o que foi revisado e se o bloco está pronto para seguir para a próxima etapa.**
